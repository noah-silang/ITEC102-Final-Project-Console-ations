# Console-ations 
## A Console-Based Donation Management System in C# 

**About the Project**
Console-ations is a C# Console Application designed to help student organizations, school clubs, community volunteers, and small charity groups manage donation records more efficiently. 
The system provides an organized way to record donations, manage donor information, calculate total contributions, and monitor progress toward a donation goal. 
This project aims to promote transparency, accuracy, and accountability in donation management while applying fundamental C# programming concepts. 

**Objectives**
- Develop a menu-driven donation management system.
- Organize and manage donor information and contributions.
- Automatically calculate monetary donations and donated goods.
- Provide an easy way to search and view donation records.
- Monitor donation goals and remaining amounts.
- Generate organized donation summaries

**Features**
1. Record a Donation – Record donor names and their monetary or goods contributions. 
2. View All Donations – Display all recorded donation transactions. 
3. Search for a Donation – Find donation records using a donor's name. 
4. View Donation Summary – Calculate and display the total number of donation records, monetary contributions, and donated goods. 
5. Manage Donation Goal – Set or update a monetary target and monitor collection progress. 
6. Input Validation – Prevent empty names, invalid categories, and invalid donation amounts or quantities. 
7. Main Menu – Navigate through the available features and exit the application.

**Technologies Used**
- Programming Language: C#
- Development Environment: Visual Studio Code
- Application Type: Console Application
- Framework: .NET

**System Requirements**
- Windows Operating System
- Visual Studio Code
- .NET SDK

**How to Run the Project**
1. Clone or download this repository. 
2. Open the project folder. 
3. Open the ".sln" or ".csproj" file using Visual Studio. 
4. Build the project. 
5. Run the application. 
6. Follow the instructions displayed in the console. 
Alternatively, using the .NET CLI: 
`dotnet run`

**Data Storage and Limitations**
- Donation records are temporarily stored in an in-memory collection.
- Records are available only while the application is running.
- The system does not use a database or permanent donation record storage.
- The application operates entirely through the console.
- The system does not include a graphical user interface, online payment processing, or a website.
